# al-business.github.io

Bu depo statik bir GitHub Pages sitesidir. Proje, tek sayfalık bir Al Business tanıtım sitesidir ve `index.html`, `about.html`, `style.css` ve `script.js` dosyalarından oluşur.

## Hızlı başlangıç

1. Projeyi klonlayın.
2. Yerelde açın veya GitHub Pages için `main` branch kullanın.
3. Tarayıcıda `index.html` dosyasını açın veya GitHub Pages üzerinden yayınlayın.

## İçerik yapısı

- `index.html` — ana sayfa
- `about.html` — hakkımızda sayfası
- `style.css` — tüm stiller
- `script.js` — mobil menü ve etkileşimli davranışlar

## Not

Bu repository, sade ve statik bir web sitesidir; bağımsız bir backend veya veritabanı gerektirmez.
